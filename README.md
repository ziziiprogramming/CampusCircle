# CampusCircle

## Overview
CampusCircle is a prototype-based full-stack campus marketplace and resource-sharing platform designed specifically for college students.

The project addresses a common problem observed in engineering colleges where students purchase academic materials such as drafter kits, calculators, lab coats, and textbooks that are later left unused by seniors. CampusCircle introduces a structured, trust-based borrowing and exchange system that connects verified students within the same institution.

This repository contains the research work, prototype documentation, deployment resources, and project structure for CampusCircle.

---

## Problem Statement
First-year engineering students often spend ₹3,000–₹6,000 on academic materials during the initial weeks of college, while seniors already possess many of these items in reusable condition.

Existing exchange systems such as WhatsApp groups, word-of-mouth communication, and general marketplaces fail to provide:
- structured discovery
- institutional trust
- accountability
- campus-focused accessibility

CampusCircle aims to solve this gap through a student-focused digital platform.

---

## Key Features
- College-verified onboarding
- Borrow-first marketplace model
- Trust and reputation system
- Personalized recommendation feed
- Notes and study material sharing
- Borrow request tracking
- Return reminders and overdue handling
- ML-based recommendation system
- Community-driven academic support

---

## Research & Validation
The project includes survey-based validation conducted among students across multiple semesters at AIKTC.

Research focused on:
- academic spending patterns
- resource reuse behavior
- willingness to lend/borrow
- trust concerns
- marketplace accessibility
